COWBELL samples

The COWBELL firmware comes with a smaller, 22 kHz copy of its cowbells built in. This page sends the full-quality set to your FM-1 over USB. It takes about ten seconds, and the samples stay through power-offs and firmware updates.

1

Connect

Plug the FM-1 in over USB with COWBELL running. Close any other program that uses its MIDI port: Windows lets only one have it. Use Chrome or Edge; the browser asks to let this page use MIDI devices.

2

Send the samples

Loading the sample bank…

    Use a different bank file

    A bank.bin made with tools/make_samples.py from your own WAV files.

    Sound stops while the samples arrive. If the cable comes out halfway, COWBELL goes back to its built-in samples; connect again and resend. Source: github.com/C0DED00D/fm1-cowbell (GPL-3.0).
